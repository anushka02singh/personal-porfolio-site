Overview

A small library of components I pulled out of real site work and cleaned up so they can be reused. Everything is plain HTML and CSS, which suits content editors that don't allow scripts, and everything is themed through a handful of shared design tokens.

What's Inside

  • Link card: a gallery index card where the whole card is clickable through one link
  • Accordion: an FAQ accordion built on native details and summary elements, with no JavaScript
  • Staff card: avatar (photo or initials), name, role and bio, with a full-width variant
  • Design tokens: colors, spacing, radius and font in CSS variables, with the font inheriting from the host site so re-theming is a few lines

Status

Published on GitHub with a live demo page and a README for each component.
