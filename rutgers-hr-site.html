Overview

A staff-facing resource page — HR & Employment, Compliance & Finance, Applications, Forms, Policies & Procedures, and Professional Development — that had quietly broken over time: links running together with no bullets, sections split apart by stray leftover tags, and styling classes with nothing behind them. I rebuilt it from the markup up, in nothing but plain HTML and CSS, since the page's CMS field doesn't render a framework.

What I Did

  • Diagnosed the actual cause of the uneven spacing and dead links: stray <hr> tags and empty paragraphs splitting a single list into several, leftover classes from an earlier framework version with no matching CSS behind them, and links sitting side by side in plain text with no bullet or anchor tag at all
  • Rebuilt every section into consistent <ul>/<li>/<a> markup so each link reads, bullets, and navigates correctly
  • Re-styled the cleaned-up lists as link cards — a left accent bar and a hover arrow — using only flexbox and basic transitions so it would render as intended inside the CMS's Full HTML field, with no JavaScript required

Status

Live as part of the department's HR & Employment resources page.
