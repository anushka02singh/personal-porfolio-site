Overview

A Next.js/React application that listens to live microphone input, detects the musical pitch being played or sung in real time, and renders animated generative flowers on a canvas. Each flower's position and appearance is driven by the detected note. I built it for an exercise in my graduate Web Programming course at Rutgers.

How It Works

  • The app asks for microphone access through the Web Audio API
  • Live audio goes into a pitch-detection model that identifies the note (C through B)
  • Each note maps to a horizontal position along a chromatic scale
  • A p5.js sketch draws an animated flower at that position, which fades and shrinks over time to make a continuously evolving visualization

What I Built

  • The full React/Next.js application structure
  • All of the pitch-to-visual mapping logic, turning detected notes into canvas coordinates
  • The p5.js flower system: procedural petal geometry, color, and fade-and-decay animation
  • The Web Audio microphone stream wired into React state and lifecycle hooks (useState, useEffect, useRef)
  • Real-time state updates for many simultaneous animated elements

Credit & Status

The pitch-detection utility was provided as course starter code by the instructor and used with attribution. It isn't included in the repository, so the repo shows my own code (the React components, canvas rendering, animation and note-to-visual mapping) built on top of it. Published on GitHub.
