Overview

CardFlow is a personal-finance dashboard. It links credit cards through Plaid, calculates a student-loan payoff timeline, and recommends which card to use for each spending category based on real rewards rates. It was an assisted project: I worked more on the design and front-end side, so that's where my own focus went.

What It Does

  • A card wallet where tapping a card opens an editable detail panel: name, owner, balance, limit, APR, cash-back destination and per-category reward rates
  • An edit mode to hide, delete or bring back cards, plus an “Add a card” tile
  • A cash-back optimizer table that recalculates instantly as cards and categories change, with an editable category list
  • A student-loan payoff calculator with a live amortization chart and adjustable sliders
  • An apartment savings tracker with an editable goal

Status

Published on GitHub with a passing test badge: 13 Jest tests run on every push through GitHub Actions. It uses Plaid's Sandbox with fake bank logins, so no real accounts are connected.
