Overview

A multi-part refresh of The Rutgers Club's site — the membership dining club's homepage banner, drink-and-dining menu, and board & staff directory. Everything was written as plain HTML and CSS meant to paste directly into the site's Drupal CKEditor field, since the theme has no support for JavaScript or front-end frameworks on the front end.

What I Did

  • Rebuilt the homepage hero banner's floating text panel — the membership message plus "Learn More" and "View Menus" buttons — repositioning and resizing it against the live venue photo through several rounds until it no longer covered the club's name in the image
  • Converted a six-category menu (Lunch Buffet, Bar, Catering, Wine, Beer, Signature Cocktails) into one tabbed page built entirely from CSS — hidden radio inputs and labels, no JavaScript — and checked it at both desktop and phone widths before handing it off
  • Rebuilt the Board & Staff directory from inconsistent source copy into uniform cards: cropped headshots where photos existed, initials avatars where they didn't, with titles and bios cleaned up and correctly attributed to the right person
  • Wrote and formatted the Announcements section — seasonal event postings, private-event closure notices, and a linked event request form — to match the rest of the site's structure

Status

Live, delivered section by section as each piece was approved and pasted in by the club's own staff.
