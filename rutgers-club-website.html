Overview

The Rutgers Club had an existing site on WordPress that needed to be migrated to Drupal. The content had to be transferred one-to-one, so the wording and structure stayed true to the original. What I could change was the interface: I designed new UI so the site still looks and feels fresh, rather than a straight copy.

What I Did

  • Transferred the content from WordPress to Drupal one-to-one
  • Built a new homepage hero banner with a floating text panel and “Learn More” and “View Menus” buttons, positioned against the venue photo over several rounds so it doesn't cover the club's name
  • Turned a six-category menu (Lunch Buffet, Bar, Catering, Wine, Beer, Signature Cocktails) into one tabbed page built entirely from CSS — hidden radio inputs and labels, no JavaScript — and checked it at desktop and phone widths
  • Rebuilt the Board & Staff directory into uniform cards: cropped headshots where photos existed, initials avatars where they didn't
  • Wrote and formatted the Announcements section to match the rest of the site

Status

Finished and handed off to my supervisor for final approval and launch. It's on a Pantheon dev site, so it isn't live yet.
